## Preserve failures and the release delta

The v0.5 primary and earlier S3/S4 HOLDs retain their original records. They are
not regraded by this qualification. Pre-freeze v1 checks also retained a stale
version assertion failure and a Windows compiler/file-use collision before their
corrections.

The frozen source's Windows CI passed. Ubuntu's installer fixture tried to
package an oversized debug binary; macOS additionally exposed unresolved temp
aliases and cleanup diagnostics. Repairs are made in a separate release checkout
while the studied worktree remains unchanged. The fixed installer checks use
release binaries with the original size cap and require the workspace version.
The macOS process-state investigation preserves permission/uncertainty failures.

At this stage, release-development changes affect verification helpers and test
drivers. Production Rust, Cargo manifests/lockfile and frozen protocol documents
are identical to the studied implementation. The final release delta and CI
results must be recorded explicitly before publication.
