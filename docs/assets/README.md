# SYMBIOTE artwork

[`symbiote-hero.png`](symbiote-hero.png) is the original project banner created for
SYMBIOTE's public presentation with the built-in image-generation tool.

The composition shows geometric reasoning cores exchanging structured fragments,
with cool cyan and warm copper light on a dark background. The image is conceptual
brand artwork; its nodes, paths and light patterns are not experimental data or a
literal topology diagram. The project name and expansion are included in the
graphic for clear attribution when displayed outside the repository.

The root README references this workspace asset directly. Keep that reference
relative so it works in source checkouts and on GitHub. The original generated
asset is preserved in this directory; project presentation changes must not alter
scientific receipts or imply unmeasured capabilities.

The banner was generated with the built-in image-generation tool on 2026-10-27,
then inspected and copied into this repository without editing the pixels.
The exact prompt is preserved in [generation-prompt.txt](generation-prompt.txt).

license; any retained upstream reference files keep their separate rights.
