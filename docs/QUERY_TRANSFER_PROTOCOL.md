# Query-policy transfer protocol 001 — proposed, not evaluated

Protocol: SYMBIOTE-QUERY-TRANSFER-001. The native register command pins the complete
recipe and protocol JSON, the full compiled source commit and intended fresh state
directory before any target truth is generated. Registration alone does not run
a pilot. No prospective result is claimed by this document.

The native registration additionally pins the actual executable SHA256 and exact
compiled Markdown protocol bytes. The qualification wrapper
`tools/transfer_campaign.py register` binds a clean full HEAD, the exact portable
source-manifest/2, native executable, native registration and protocol document.
Its separately saved registration digest is required by `run`; preflight repeats
these checks before the once-only marker and target creation, then independent
raw verification repeats them after execution. A source stamp alone is not build
attestation. Manual binding/tamper fixtures do not invoke the cohort generator.

The source, calibration and target phases are separate. Each actor receives two
source graphs with four nodes and two paths; actual observations derive a ranked
query prior. The weighted score for each public endpoint role is exactly
sum(cost - lower) / sum(upper - lower), compared by integer cross multiplication.
A role requires observations in two named source contexts. Ties are FromStart,
Interior, ToGoal, Direct. Missing roles retain optimistic-route edge order after
trained roles. Named contexts are provenance partitions, not proof of independent
statistical sampling.

A prior may select only an unknown edge on RouteLearner's exact optimistic route.
It supplies no observation or constraint and never certifies a route. Positive
cost intervals, exact support, contradiction, abstention and conditional
certification remain the existing engine's responsibility. A separate
Bellman-Ford evaluator checks the truth cost; its result never selects a query.

Each actor's own policy is independently calibrated on two six-node graphs.
The source roles are complementary: one partner has start-edge penalties and the
other goal-edge penalties. After inert JSON exchange, each receiver uses two
separate six-node calibration contexts for its own proposed target pattern.
Promotion requires exact correctness, no regression against original default,
strictly fewer queries than its current selected behavior, and no regression on
any previously recorded family counterexample. Accepted changes supersede the
single current prior; historical receipts and revisions remain. A known harmful
ranking cannot regain acceptance by renaming its artifact, source or context.

The complete prospective recipe is four seeds (7, 19, 43, 101), two separately
reported oracle prices (1 and 100), two actors, and six arms: isolated-prior,
fresh-default, fixed-start, fixed-goal, local-trained and exchanged. This gives
48 paired cells. Every actor has two final graphs, with eight and ten nodes; the
second adds a cross edge. Source, calibration and final context IDs differ.
No final target is used for query-policy promotion. Queried target facts are
separately evaluated and retained in every arm's KnowledgeStore, as described
below; those checks are not independent policy-generalization samples.

The alternate path's first public lower bound is 2; other lower bounds are 1
and all upper bounds are 9. Thus the first path is uniquely optimistic before
the verified complete node/edge permutation. Its private penalty is 4 + seed % 6
at the start or goal edge. This avoids a node-name tie breaker as the calibration
treatment. The generator is deterministic controller code pinned by source
commit and recipe digest. Seeds and cost-family labels are never policy inputs.
Seeds 7, 19 and 43 all give penalty 5; seed 101 gives penalty 9. The 16 distinct
labelled target tasks are reused across six arms and two prices (192 target
evaluations). They are not 192 independent worlds. Each output carries full
schema/cost/task hashes and a complete endpoint-aware canonical weighted graph
witness. Unique colour refinement establishes the witness; unresolved symmetry
abstains. Equal full witnesses establish weighted graph isomorphism. The report
lists exact collision groups without making a statistical significance claim.

All arms share query/model budgets. Fresh and fixed controls may skip unneeded
training and spend less; they are not artificially charged for observations they
did not make. Local-trained acquires fresh target-domain source observations and
passes its own disjoint calibration. Exchange pays both agents' source
acquisition, including unused offers; self and receiving evaluation, default and
incumbent trials, each evaluator's full calibration truth pass,
the target evaluator's full truth pass and two subroute truth passes,
model/policy/verification work and canonical refinement scans,
actual restart replay work, both send and receive KiB units, adoption, and
negative qualification probes. Costs are declared logical units, not hardware
speed. Diagnostic overhead is charged to the exchange arm conservatively.

All arms retain only edges accepted during their actual target query sequence.
Two endpoint-disjoint one-edge subroutes from the certified main route are
evaluated separately by Bellman-Ford before graph-fact promotion. Their query
inputs differ from the main acquisition route, and the empty pre-acquisition
map must abstain. The trusted controller creates inert oracle envelopes bound
to authority, observer identity, context, schema, sequence and edge cost. These
hash-bound local laboratory envelopes do not authenticate an external agent.
They and the exact assessment remain in knowledge.jsonl. The graph domain is
strictly bounded to 2..12 nodes, 56 edges and edge costs 1..9; encoded prediction
costs remain 1..63. Unsupported larger outputs fail explicitly. This adds
10/12-node support without changing old receipt serialization or approximating
the exact route solver.

After both target tasks, every actor drops and reopens its actual Store,
StrategyLedger and KnowledgeStore. Owner, history heads, raw ledger bytes and
model digests must match, and nonempty main/subroute predictions must remain
correct with zero new authority calls. Exchange actors repeat this after
negative policy probes: revoking a bad query prior must preserve valid graph
facts. Graph forecast work uses actual exact-learner counters on the controller
thread, including admission, commit validation, replay and retained predictions.
This is persistent verified fact retention, not a new independent transfer trial.

The report exposes the complete per-participant Bill: source_queries,
calibration_queries, calibration_truth_edges, target_queries, target_truth_edges,
retention_truth_edges, diagnostic_queries, diagnostic_truth_edges,
computation_work, replay_work, exchange_bytes, exchange_units and adoption_units.
All query/edge-read fields are multiplied by the separately reported price;
work, exchange units and adoption are then added. Acquisition already paid for
main target queries is included in graph-evidence accounting but is not charged
twice in the Bill. Each actual sent/received source JSON wire is saved byte for
byte with its path and SHA. Final per-cell receipts point to each private ledger.

Both fixed role orders are measured. The best fixed order per participant is
also reported as a labelled hindsight bound, not a deployable selector.

Before executing the cohort, independent source review predicts that the strong
utility criterion below is structurally dominated: the source observations cover
only FromStart and ToGoal, so their learned ranking is already contained among
the two fixed-role controls. The matching fixed policy can make the same target
queries without the additional training, calibration and exchange overhead.
The expected strong-utility result is therefore `NOT_DEMONSTRATED`. This frozen
pilot tests portable policy mechanics, negative controls and retained facts; it
cannot establish an advantage over that hindsight policy class. A richer policy
class would require a separately declared experiment, without retuning this one.

Positive reciprocal utility requires strictly lower full cost for both
participants, with no lost certification or new errors, against fresh,
local-trained and best-fixed controls on every normal-price seed. If those
controls remove the gain, report NOT_DEMONSTRATED. Cheap-price outcomes remain
separate. No automatic version advancement follows a software PASS.

Negative probes include unsupported declared policy grammar, observed interval
drift, and a valid-family inverted-cost prior. Harm is determined by actual
queries/outcomes, never by a hidden family label. A proved harmful prior is
durably revoked and restart must retain that change. Other correctly behaving
priors are not revoked merely because a family name changes.

Bounds: 60 seconds for the controller, 24 oracle queries and 10,000 model/policy
work units per task, 10,000,000 logical cost units per actor, bounded source and
calibration sets, and bounded owner-anchored strategy journals. A started state
or existing receipt is never retried or overwritten. Completed cell receipts and
private state survive failure. This is a single trusted controller experiment;
external-agent authorization and native multi-process topology are separate
engineering work. It does not establish universal transfer, multi-host operation,
generalized intelligence, statistical significance or autonomous self-improvement.

Stage-one tests use explicitly named manual fixtures only and do not invoke the
prospective cohort generator or registered pilot. Before evaluation: review this
protocol and code, freeze a source commit, build with that source stamp, create a
new registration, retain its SHA independently, then run exactly once.
