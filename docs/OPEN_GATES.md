# Open gates after v1.1.2

v1.1.2 remains the latest stable engine at source
`8aa5f4c6ab26f7ccad53935a70414ae1765b57c6`. This register does not move that
tag, replace its assets, or regrade a failed release, protocol 001, the
cancelled hour, or the frozen parity table.

A row closes only when its own rule records `PASS`, `NOT_DEMONSTRATED`, or the
permanent exclusion already written here. `HOLD` leaves the row open. A
finished negative study stays negative. It is not a reason to retune and rerun.
A new version number closes nothing in this table.

Completed studies already support the current efficiency sentence in
[the engine status](V11_ENGINE_STATUS.md): isolated learners tie, ordinary
transfer costs more recorded work than isolation, and reciprocal efficiency is
**NOT_DEMONSTRATED**. That sentence is not a Protocol 002 result. Protocol 002
is still **NOT_RUN**.
