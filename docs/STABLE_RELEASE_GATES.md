# Path to a stable bounded SYMBIOTE

The stable target is an embeddable Rust agent with exact reasoning, reciprocal
exchange and evaluated persistent knowledge in its declared affine and graph
families. Stable software does not establish general intelligence, arbitrary
remote truth or universal transfer efficiency. The original version objectives
remain in [the roadmap](ROADMAP.md); unsuccessful research criteria stay visible.

## Finish the prospective relationship study

Freeze source and environment before opening the 24-world cohort. Execute the
registered primary study once under protocol 004. Preserve every failure,
abstention, harmful exchange and unfinished case. Independently recompute costs,
coverage, provenance and paired comparisons from raw artifacts. A negative
selection result constrains the claim; it does not authorize outcome tuning.

Before evaluation, the additional nonvacuity rule is explicit: every group must
preserve all accepted models, profiles and authority counters across restart.
The positive persistent-learning summary additionally requires at least one
shared validated retained context for A and B1 in the normal-price prospective
group at final restart, correct nonempty offline predictions for each, zero
observe/verify/assess calls during replay, and at least one post-midpoint decision
by central A that uses its prior durable completed outcomes. B1's profile-use
count is reported separately. Empty controls are reported separately. Equality of two
empty model lists establishes no learned capability. This evidence rule changes
neither the frozen policy, cohort, prices nor protocol 004's utility criteria.

## Make identities and trust maintainable

Add an offline, explicit policy transition anchored to the previous policy digest
and operational journal head. Preserve owner identity and every historical byte.
Use coordinated downtime for certificate rotation; keep denials unless a separate
operator action explicitly regrants access. Restrictive changes must cancel
uncommitted intents before recovery can promote them.

Required checks: old pins stop working, new pins retain identity, denied peers
remain denied, stale transitions fail, unauthorized permission widening fails,
and interrupted transitions recover or produce an actionable HOLD. Current
immutable-policy rejection is safe but is not a complete credential lifecycle.

## Make durable state portable and reproducible

Add verified offline backup and restore into a new directory. Include identity,
knowledge, operational registration, deny history, idempotent receipts and layout
metadata. Hash every required file. Exclude private keys by default and declare
their provisioning requirement. Never overwrite an existing restoration target.
Separately support restoration of the original genesis-only laboratory setup so
opaque identity ordering can be reproduced without copying learned outcomes.

Required checks: exact restored identity/history/predictions, persistent denials
and receipts, rejected altered or missing files, interrupted restore isolation,
and reproducible logical decisions from the recorded simulation setup. Do not
promise byte-identical timings, cryptographic nonces or operating-system counters.

## Qualify one bounded release candidate

Declare and run a finite campaign covering both task families, independently
supervised peers, explicitly authorized private-network deployment, crashes,
lost acknowledgements, drift, exhausted budgets, rotation and restoration.
Keep the campaign's budgets and acceptance rules fixed. Publish its failure
envelope, supported Rust/API/protocol/state-format window and platform results.
Verify native archives, installation and restart using the actual public assets.

Secure configured APIs on one host are distinct from independent multi-host
deployment evidence. Missing deployment evidence remains an open gate rather
than a claim inferred from accepting a non-loopback address.

Larger networks, online enrollment, automatic renewal, new task families and
broader learning advantages are subsequent research. They must not be implied
by a stable release of the bounded core.
