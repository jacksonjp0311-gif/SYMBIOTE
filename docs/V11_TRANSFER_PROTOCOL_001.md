# SYMBIOTE-V11-TRANSFER-001 — prospective local engine transfer

Status at declaration: NOT_RUN. This new bounded engineering experiment supports
the v1.1 engine contract. It does not amend/repeat any closed cohort, Engine
Evolution 002, or the preserved transfer-research Protocol 002. The
[machine specification](V11_TRANSFER_PROTOCOL_001.json) is normative.

## Tasks and controls

Use two pairs of width-eight affine Boolean sources. For pair index `i` in 0,1
and role `a`,`b`, SHA256 the UTF-8 string
`SYMBIOTE-V11-TRANSFER-001/case/{i}/{role}`. Mask is `1 + byte[0] mod 255` and
bias is `byte[1] & 1`: (106,1)/(79,1) and (101,1)/(140,1). These related finite
tasks are not independent scientific samples.

Each arm has two distinct persistent owners, explicit source/scope/epoch and
budget authorization. Transfer learns its own scope from individual observations,
exports the exact original record, grants bilateral local permission using actual
owner handles, quarantines, independently evaluates incoming knowledge through
its own source, and retains the exact original artifact/digest. Local validation
audits remain separate. Tickets bind participants, artifact, policies/evaluator,
source epoch, original request and before-knowledge anchor.

Controls are an optimized isolated structural learner, a matched-permitted-source
and reasoning-budget structural learner, and an exact answer cache. Structural
controls use the same compact solver and rank-basis-min/v1 policy, acquiring both
scopes themselves. Cache stores only the identical individual answers. Per-source
admission is 16 queries and 1,000,000 GF(2) units. Matched allowances are not
automatically equality of all physical resources.

Separately owned source processes deliver bounded authenticated individual
observations. Rust receives descriptors/endpoints and private bearer paths, never
mask/bias, tables, evaluation inputs or labels. Own acquisition and incoming
verification use distinct sessions. Commitments open after predictions commit;
retain actual response/request bytes and transcript hashes. Honest sources,
native code and the frozen supervisor remain controlled assumptions.

## Freeze, actual restart, fresh use and feedback

Freeze both identities/configurations, models, exact transferred artifacts,
anchors and tickets; close acquisition. Stop and wait for all observation sources
before revealing tasks. Select 32 inputs by ascending SHA256 of UTF-8
`SYMBIOTE-V11-TRANSFER-001/case/{i}/input/{input}`, excluding every acquisition
and validation input across arms. Horizons 1,16,32 are fixed-list prefixes, not
independent trials or adaptive stopping choices.

A different OS process opens retained state and records each actual fresh use
through ordinary Engine APIs, without source callbacks/labels. Sync and commit
the complete prediction receipt before grading. Hold the live process at an
explicit host barrier, kill only that owned process, and observe actual exit.
Preserve committed predictions. Invoke the explicit engine stopped-owner
recovery API: actual OS-dead locks only, no manual unlink, identity reset or
invented outcome. Another process reopens, completes native feedback, and
reconciles against the actual receiver's live checked ledgers. Reopen/reconcile
again: credit and journal bytes must not grow.

Both directions independently acquire useful knowledge before a bilateral
conditional-capability claim. Existing feedback marks fresh uses Conditional
when labels were absent from original evaluation. External grading correctness
must not become fabricated known-use or measured-benefit flags. Unknown costs,
cache abstentions and optimized-isolation ties/losses retain those labels.
