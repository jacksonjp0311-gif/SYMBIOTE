# Evidence-gated evolution

These are version objectives, not automatic capability promises. Later-feature
prototypes in Genesis do not justify skipping the associated research gates.
Maintain failed criteria and matched-cost controls for every release.

| Version | Objective | Required next evidence |
| --- | --- | --- |
| v0.1 Genesis | Clean BRUTE derivative; native exact reasoning; authorized telemetry; independent vertical slice | Delivered local finite-domain loop, exact parity, persistence, rollback, reciprocal strategy acceptance and honest controls |
| v0.2 First Symbiosis | Two-way structured exchange | Independently implemented partners and held-out tasks; useful unsolicited contributions; no teacher-table leakage; matched-cost controls |
| v0.3 Adaptive Memory | Durable versioned learning with rollback | Broader task representations, crash/recovery campaigns, independent evaluation isolation and migration compatibility |
| v0.4 Reciprocal Improvement | Benefits to both systems | Paired repeated experiments against isolated adaptive learners; include all costs and regressions; no repeated-case inflation |
| v0.5 Adaptive Relationships | Select useful partners | Prospectively predict usefulness from telemetry and validate selection on unseen partners; similarity is insufficient |
| v0.6 Transferable Knowledge | Reuse abstractions | Unfamiliar tasks, channel/action remapping, negative transfer, wrong-family controls and persistent held-out gains |
| v0.7 Symbiotic Networks | Controlled topology | Consent per edge, bounded aggregate budgets, network failures and independently tracked individual benefits |
| v0.8 Self-Directed Exploration | Select experiments within limits | Audited experiment choice, information gain vs cost, cancellation, independent approval boundaries and no unsanctioned attachment |
| v0.9 Generalization and Stability | Adversarial and drift stress | Wrong/malicious knowledge, dishonest APIs, long-running stability, drift, resource exhaustion and recovery |
| v1.0 Stable SYMBIOTE | Reliable embeddable Rust system | Secure nonlocal transports, reproducible reciprocal learning across multiple independent controlled environments, compatibility and documented failure envelope |

The v0.2 implementation now exercises two different native learning algorithms,
exact active queries, held-out inputs and reciprocal verified evidence reuse.
Its trusted local oracle and declared cost model are explicit limitations; both
learners still share one controller process. See [v0.2 research](RESEARCH_V02.md).

v0.3 adds two supervised native peer processes, private retained knowledge,
byte-preserving migration and explicit crash recovery. Its TLS transport is
tested separately as a library; the process experiment still uses authorized
loopback v1. Graph reasoning is a verified primitive, with operational graph
learning still pending. See [deployment evidence](../experiments/v0.3/deployed-verification.json).

Next: turn route planning into a second persistent exchange task, integrate TLS
into the supervised runtime, and evaluate partner choice prospectively.
Predeclare compute budgets, rejection criteria and participant utility. The
broader v0.4–v1.0 claims remain open; local software success does not automatically
advance those versions.
