# Iterative release work

The owner authorized repeated implementation, testing, independent review and
publishing toward the existing stable v1.0 goal, with routine engineering decisions
delegated to the implementer. Passing a software gate cannot substitute for a
missing scientific claim. The v1.0 criteria in ROADMAP.md remain in force.

## Cycle 1: establish the baseline

Before editing, all 33 v0.1 tests passed on the clean released checkout. Original
BRUTE source, parity fixtures and historical Genesis receipts remain unchanged.

## Cycle 2: close the active-reasoning gap

Added exact finite Boolean affine inference with deterministic maximin query
selection, budgets and explicit observed/inferred/uncertain/unavailable states.
Received hints never restrict support. Identification needs width+1 independent
observations; hint-only transfer cannot defeat that bound. This negative result
directed the next implementation rather than being concealed.

## Cycle 3: reciprocal evidence reuse

Two native learners use different algorithms: complete hypothesis enumeration and
Gaussian elimination. They acquire complementary source observations over real
authorized loopback TCP, verify received witnesses against a separate lab oracle
registry, replay evidence into full local learners and predict held-out inputs.
The independent evaluator materializes truth before learning. Source acquisition
is charged to both participants. The explicit observation-cost model includes
verification, transfer, adoption and prediction; CPU/controller/evaluator work is
not priced, so it establishes no wall-clock or universal efficiency advantage.

Review corrections: label receipt-based endpoint inference provisional until
independent held-out assessment; do not call matching persisted records model
reuse during a benchmark that deliberately reconstructs fresh learners; do not
label seeded contexts statistically independent when their laws can repeat.

## Cycle 4: durable knowledge and usable delivery

Added schema-bound declarative knowledge, distinct training/evaluation evidence,
per-owner ledgers, revision/alias checks, offline retained predictions and rollback.
Readable commands, nonmutating diagnostics, original banner, updated README and
checksum-verified native binary bundles make the research slice easier to run.

## Cycle 5: process and memory stability

The v0.3 candidate adds supervised operating-system peers, measured retained
prediction with zero oracle requests, explicit crash recovery and audited
byte-preserving migration. Shared initialization gates protect both owner checks
and Genesis commits. A deterministic independent-review test reproduced the
previous conflicting-owner race before the fix; the same test then passed.
Copied private identities and incompatible retained schemas are refused before
learning. Real crash-after-commit tests retain knowledge across failed replies.

The separately tested TLS 1.3 library validates mutual certificates, names, pins,
scope and grants before application data. Its resource budgets include failed
connections. Unknown peer revocations cannot grow state, and admitted handler
completion after revocation is explicitly documented rather than hidden.

Graph interval reasoning is verified as a second native primitive. It has not yet
earned network-learning or durable graph-knowledge claims. Stable v1.0 therefore
remains a separate target after the v0.3 delivery gates.

## Current advancement boundary

v0.2 and v0.3 are verified local research increments. Neither is the stable v1.0
endpoint. Outstanding criteria include externally operated or nonlocal partners,
multiple unfamiliar task families, secure nonlocal
transport, long-run/crash/migration campaigns, validated partner selection and
autonomous experiment selection within explicit limits. Preserve failed criteria
and old evidence while implementing and assessing each subsequent cycle.
